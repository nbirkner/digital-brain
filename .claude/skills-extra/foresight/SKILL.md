# /foresight

The value here is the cross-domain view. Things that look fine in isolation often look different when you see all of Niki's life at once.

## How to run

Read these files before generating output:
- `personal/context/general/goals.md` — Q2 priorities, open loops, key dates
- `personal/context/general/soul.md` — current emotional/relational state
- `personal/docs/health/lab-tracker.md` — health trajectory
- `personal/context/life-areas/finances.md` — financial state
- Any recent session logs in `shared/docs/logs/`
- Any recent journal entries in `personal/docs/growth/journal/`

## What to look for

**Cross-domain tensions:**
- Is a work sprint colliding with a relationship need?
- Is financial stress running quietly underneath everything else?
- Is health protocol slipping during a heavy work period?

**Overlooked momentum:**
- What's building in one domain that could accelerate another?
- What's being neglected that will cost more later?

**Decision quality:**
- Any upcoming decisions where having full context (health + finances + work + relationship) changes the calculus?

**Calendar-aware nudges** (if Google Calendar MCP is connected):
- What's coming up in the next 2 weeks that needs prep?
- Any conflicts or back-to-back drains that should be flagged?

## Output format

```markdown
## Foresight: [date]

### Cross-domain view
[2-3 sentences on what's happening across all domains together]

### Tensions worth naming
- [specific collision between domains]

### What's being quietly neglected
- [the thing that keeps getting pushed]

### One strategic nudge
[A single, specific, non-obvious recommendation that only makes sense from this zoomed-out view]

### Coming up to watch
- [key dates/events in next 2 weeks]
```

This is a thinking partner output — not a to-do list. The goal is one insight that Niki wouldn't have had without zooming out.
