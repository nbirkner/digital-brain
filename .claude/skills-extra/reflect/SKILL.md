# /reflect

Pull patterns from recent activity and surface what's actually happening — not just what happened.

## How to run

1. Read `shared/docs/logs/` for the last 7-14 days of session logs
2. Read `personal/docs/growth/journal/` for any recent check-ins
3. Read `personal/context/general/goals.md` for stated priorities
4. Cross-reference: where is time/energy actually going vs. stated priorities?

## What to surface

**Behavioral patterns:**
- What decisions keep coming up? Any that feel like the same problem twice?
- Where is momentum building? Where is it stalling?
- What tasks/contexts consistently get deferred?

**Energy patterns:**
- What work generates energy vs. drains it?
- What time of day/week is the most productive?

**Relationship patterns:**
- Any stakeholder dynamics worth noting?
- What's unresolved in personal context?

**Alignment check:**
- Compare Q2 priorities (personal/context/general/goals.md) to what actually got worked on
- Flag any drift between stated intentions and actual activity

## Output format

```markdown
## Reflect: [date range]

### Momentum
- [what's building]

### Friction
- [what's stuck or recurring]

### Drift
- [where stated priorities and actual activity diverge]

### Pattern worth naming
- [one behavioral insight worth holding]

### One thing to try differently
- [concrete, specific, not generic]
```

Save to `personal/docs/growth/journal/reflect-YYYY-MM-DD.md`.
